# .github Configuration Repository

此仓库是 **VisiGap** 组织的专用配置仓库 (Health Files)。

这里存放的文件将作为组织内所有仓库的**默认配置**。如果某个具体的仓库中没有创建特定的文件，GitHub 将自动应用这里的文件。

### 📂 目录结构说明

此仓库包含以下全局配置文件：

*   **`profile/README.md`**: 
    *   组织的公开主页介绍（即你点开 VisiGap 主页看到的内容）。
    
*   **`CODE_OF_CONDUCT.md`**: 
    *   全局社区行为准则。
    
*   **`CONTRIBUTING.md`**: 
    *   全局贡献指南（教大家如何提 PR）。

*   **`SECURITY.md`**:
    *   安全策略（告诉大家发现漏洞怎么联系我们）。

*   **`ISSUE_TEMPLATE/`**: 
    *   包含默认的 Bug 报告和功能请求模板。

*   **`PULL_REQUEST_TEMPLATE.md`**:
    *   提交代码时的默认填写模板。

### ⚠️ 维护注意

1. **谨慎修改**：修改此仓库的文件会影响组织下的**所有**项目。
2. **覆盖规则**：如果某个项目（例如 `VisiGap/Game-Server`）需要特殊的贡献规则，请在该项目中创建同名文件，它会覆盖此处的全局默认设置。
